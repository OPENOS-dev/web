快速开始

在 Linux 环境下构建 OpenOS 系统镜像，或使用 QEMU 在 macOS 上快速体验。

Linux Build

构建系统镜像

在 Linux 主机上使用 build_packages 和 build_image 工具生成 OpenOS 镜像。

→ macOS QEMU

本地运行演示

使用 QEMU + macOS Hypervisor.framework (HVF) 加速运行 OpenOS 演示镜像。

→ Source Code

源码仓库

使用 repo 工具克隆 OpenOS 完整源码，包含 100+ 个 Git 仓库。

→ Documentation

技术文档

阅读 OpenOS 架构说明、平台服务 API、构建系统详细文档。
