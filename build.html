快速开始

在 Linux 或 macOS 上构建 OpenOS，或直接使用预编译镜像快速体验。

Build from Source

从源码构建

克隆 OPENOS 仓库，使用 Arch Linux 环境编译内核、安全模块、桌面与包管理工具。

→ GitHub 仓库 QEMU on macOS

在 macOS 上运行

通过 QEMU 虚拟机在 macOS 上直接运行 OpenOS，无需物理设备即可体验全部功能。

→ 操作指南 Download ISO

下载预编译镜像

获取最新稳定版 ISO 镜像，烧录至 U 盘或直接用于虚拟机安装。

→ 镜像列表 Projects

快速构建命令

git clone https://github.com/OPENOS-dev/OPENOS.git
cd OPENOS
./scripts/build.sh --target=x86_64

更多构建选项请参阅 README。
