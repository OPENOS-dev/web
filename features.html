核心特性

基于 Arch Linux 构建，从内核到桌面完全自主设计，形成独立的开源操作系统发行版。

O

OAK 安全基座

内核级非对称加密与进程保护，不依赖 TPM 或任何专有硬件模块。支持 OAK-Seal 硬盘加密绑定，确保系统完整性。

U

OPENUI 桌面

基于 Wayland + wlroots 与 Qt/QML 的自研桌面环境，轻量高效，支持 NUI 设计规范。默认极简无广告，专注用户操作。

P

OPT 统一包管理

同时支持 pacman 与 apt 双后端，通过 OPT 统一调度。首次启动自动配置，支持软件命名空间隔离，避免依赖冲突。

V

软件命名空间隔离

内核级轻量虚拟化，为每个应用提供独立的文件系统视图。调用耗时 < 1 秒，无需完整容器，资源占用极低。

C

跨平台支持

支持 x86-32、x86-64、ARM32、ARM64、LoongArch64 五大架构，覆盖从老旧设备到现代硬件的广泛范围。

L

OPL 开源许可

基于 OPENOS-PROJECT-LICENSE（OPL）发布，保障代码自由、设备自由、体验自由与操作自由。完全免费，不受硬件限制。

OpenOS

基于 Arch Linux 的开源操作系统，由 OPENOS-dev 维护。
