# 2026-07-20

## OpenOS 介绍网站开发
- 为 OpenOS（基于 ChromiumOS 的开源操作系统）创建了介绍网站
- 使用 **NOTHING UI v1.0** 设计系统，严格遵循设计规范中的所有 CSS 变量
- 单文件 `index.html`，包含完整的内嵌 CSS 和 JS
- 内容涵盖: Hero、核心特性(6张卡片)、系统架构(6层层叠)、硬件支持(4芯片平台)、核心组件表、构建指南、源码结构
- 侧边导航栏 + IntersectionObserver 滚动监控
- 响应式设计，支持移动端
- 本地服务器运行在 http://localhost:8080

## 设计重构（参考 open-code-studio.github.io/website）
- 用户要求更换为 #4AA26F 绿色强调色，模仿参考站的简洁单页设计
- **完全重构**：从多 section 长页面改为简洁的单 Hero + 4 区块结构
- 强调色：#4AA26F (绿)，带渐变到 #6BC48D
- 页面结构：
  - 固定顶部导航 (48px 高) - Logo + 5 个链接
  - Hero 区 (占满视口) - Badge + 大标题(渐变) + 副标题 + 双按钮 + 8 个技术标签
  - 01 Features - 6 个核心特性卡片
  - 02 Projects - 6 个项目卡片 (含 active/stable 状态徽章)
  - 03 Quick Start - 4 个入口卡片
  - 04 About - 3 个关于卡片
  - Footer - 居中 Logo + 链接 + 版权
- Section header 风格：mono 字体小标签 "// 01 · FEATURES"
- 卡片使用 surface-1 背景 + subtle border
- 2px 圆角保持，4px 宽滚动条
- 移动端汉堡菜单 + 768px 响应式断点
- Fade-in 动画 + IntersectionObserver 滚动触发
- 本地预览：使用 npx @playwright/cli 进行截图验证
