核心项目

OPENOS 生态的核心组件，涵盖操作系统、安全模块、桌面环境与工具链。

OPENOS 操作系统

active

基于 Arch Linux 的操作系统核心，包含内核补丁、安全模块、桌面环境与包管理前端。

内核 Arch Linux Wayland

OAK 安全基座

active

开放平台非对称加密技术，内核级 LSM 模块，支持进程保护、OAK-Seal 硬盘加密与 OPEN RSA 协议。

安全 内核模块 LSM

OPENUI 桌面环境

active

基于 Wayland + wlroots 与 Qt/QML 的桌面外壳，遵循 NUI 设计规范，默认无广告、键盘优先。

Wayland Qt NUI

OPT 包管理器

planning

统一包管理前端，支持 pacman 与 apt 双后端，提供软件命名空间隔离、首次启动自动配置。

包管理 pacman apt

NUI 设计规范

active

NOTHING UI 设计规范，定义 OPENOS 桌面交互、视觉风格与设计令牌。NUI1/NUI2 已开源。

设计规范 UI/UX 开源

OPL 许可证

active

OPENOS-PROJECT-LICENSE，保障代码自由、设备自由、体验自由与操作自由的专有开源许可证。

许可证 开源 OPL

软件命名空间隔离 (SNI)

planning

内核级轻量虚拟化，为每个应用提供独立文件系统视图，调用耗时小于 1 秒，资源占用极低。

虚拟化 内核 隔离
