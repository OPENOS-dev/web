核心项目

由 OPENOS-dev 维护的 OpenOS 生态核心组件，涵盖构建工具、平台服务和虚拟化方案。

OpenOS Core

active

OpenOS 操作系统核心，基于 ChromiumOS 衍生，提供完整的系统镜像、内核和系统服务。

chromiumos platform2 kernel

Chromite Build

active

Chromite 是 ChromiumOS/OpenOS 的核心构建工具集，Python 编写，驱动整个 CI/CD 流程。

python build ci-cd

OpenOS Firmware

active

开源固件集合，集成 coreboot、depthcharge、EC 嵌入式控制器，覆盖 X86 和 ARM 平台。

coreboot uefi arm

crosvm Hypervisor

stable

基于 KVM 的虚拟机监视器，支持 Android Runtime、Linux 容器、borealis-vm (Steam) 等多场景。

kvm rust arc

NOTHING UI

active

OpenOS 默认界面语言，深色优先、高密度、数据驱动的设计系统。基于 Material Design 3 叠层模型。

design-system react css
